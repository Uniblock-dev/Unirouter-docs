AI Interview Coach is a mock interview app built on Hopscotch. You paste a job description, can add a résumé, and answer questions by typing or speaking. Each answer gets a score and specific feedback, and the session ends with a practice plan.

## Overview

AI Interview Coach helps job seekers practise for one specific role. The questions come from the job description and résumé the user provides, so they match the role instead of a generic list.

## How Hopscotch Helped

The coach needs three kinds of models: a chat model that returns valid JSON, a model that turns speech into text, and a model that reads questions aloud. Hopscotch provided all three through one API.

- **One integration.** The app uses the standard OpenAI SDK pointed at Hopscotch. Chat, transcription and speech all run on one API key and one prepaid balance.
