## Before you start

You need three things:

<Steps>
  <Step title="A verified account">
    Sign up and verify your email address at [platform.hopscotchlabs.ai](https://platform.hopscotchlabs.ai).
  </Step>
  <Step title="A workspace with credit">
    Credit is prepaid, so a workspace with a zero balance refuses requests before they reach a provider.
    The workspace owner or an admin buys credit on the Billing screen. See [buying credit](/manage/buy-credit).
  </Step>
  <Step title="An API key">
    Mint one on the Keys screen. The key appears once and we keep only a hash, so we cannot show it
    to you again or recover it for you. Copy it before you leave the screen.
    See [authentication](/get-started/authentication).
  </Step>
</Steps>

## Set the base URL

<BaseUrl />

| Where | Value |
|---|---|
| An OpenAI SDK `base_url` / `baseURL` | `https://api.hopscotchlabs.ai/v1` |
| A raw HTTP call | `https://api.hopscotchlabs.ai/v1/chat/completions` |

## Send your first request

<CodeGroup>

```bash curl
curl https://api.hopscotchlabs.ai/v1/chat/completions \
  -H "Authorization: Bearer ub_live_YOUR_KEY_HERE" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-4o-mini",
    "messages": [{"role": "user", "content": "Say hi in five words."}]
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.hopscotchlabs.ai/v1",
    api_key="ub_live_YOUR_KEY_HERE",
)

response = client.chat.completions.create(
    model="openai/gpt-4o-mini",
    messages=[{"role": "user", "content": "Say hi in five words."}],
)

print(response.choices[0].message.content)
```

```javascript Node
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://api.hopscotchlabs.ai/v1",
  apiKey: "ub_live_YOUR_KEY_HERE",
});

const response = await client.chat.completions.create({
  model: "openai/gpt-4o-mini",
  messages: [{ role: "user", content: "Say hi in five words." }],
});

console.log(response.choices[0].message.content);
```

</CodeGroup>

The response is the OpenAI chat completion shape.

## Troubleshooting your first request

Every error uses the same JSON body. Branch on `error.code`, not `message`. Quote `error.request_id` (also the `x-hopscotch-request-id` header) if you contact support.

| Status | `code` | Cause | Fix |
| --- | --- | --- | --- |
| 401 | `invalid_api_key` | Key missing, not sent as a Bearer token, wrong shape, or not accepted. | Send `Authorization: Bearer <key>`. Check you copied the whole key. Lost keys can't be recovered, so create a new one on the Keys screen. |
| 402 | `insufficient_credit` | The workspace can't cover the request's estimated maximum cost. | Have the workspace owner or an admin buy credit on the Billing screen. See [buying credit](https://docs.hopscotchlabs.ai/manage/buy-credit.md). |
| 400 | `model_id_not_pinned` | `model` has no provider prefix. Common when migrating OpenAI code. | Use `openai/gpt-4o-mini`, not `gpt-4o-mini`. A `profile/` slug or `unirouter/auto` also works. |

Don't retry these unchanged. Fix the key, credit, or model id first.

A `404` with `model_not_found` is usually a typo. Run `GET /v1/models` to list what your key can call. All other codes are in [Errors](https://docs.hopscotchlabs.ai/api-reference/errors.md).
