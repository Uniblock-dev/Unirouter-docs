[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness), whose command is `dsh`, is DeepSeek's open agent runtime. The model adapter, tools and agent loop are all swappable, and it ships a web interface, a headless mode and an ACP server. Read [coding harnesses](/integrations/coding-harnesses) first.

The name is a coincidence. The harness is DeepSeek's, and the provider you add here is this one. Which models you reach is decided by the ids you pin.

## The configuration surface is a form

The first-class path is a settings screen, not a file. In the web interface, open **Settings**, then **Models**, and choose **Add a custom provider**. It asks for a lowercase provider id, a display name, a base URL, an API protocol and a credential. Then it asks for at least one model.

```text Base URL
https://api.hopscotchlabs.ai/v1
```

**Pick `openai-completions` as the protocol.** The other two offered are `openai-responses`, which [Codex CLI](/integrations/codex-cli) documents, and `anthropic-messages`, which this site publishes nothing about. A provider speaks one protocol, so a gateway serving two needs two entries.

**The provider id is permanent.** Requests, saved sessions, model defaults and credential references all use it. Renaming means adding a provider and deleting the old one. Model changes take effect on the next request, with no restart.

## The file behind the form

The form writes `$DSH_HOME/settings.yaml`, section `llm-pi-ai`. You can edit it directly, and you must for anything the form leaves out:

```yaml $DSH_HOME/settings.yaml
llm-pi-ai:
  providers:
    hopscotch:
      api: openai-completions
      baseURL: https://api.hopscotchlabs.ai/v1
      apiKeyEnv: HOPSCOTCH_API_KEY
      models:
        - id: unirouter/auto
```

```bash
export HOPSCOTCH_API_KEY=ub_live_YOUR_KEY_HERE
```

The form holds the key, display name, base URL, protocol, and per model an id, a context window and a maximum output. Reasoning levels, image input, compatibility switches, headers, timeouts and retry policy are in the file only.

A key entered through the form is stored in `$DSH_HOME/.credentials.yaml`, and settings keep a reference. The page is write-only and never shows the secret again. `apiKeyEnv` keeps the value in your environment. Either way the credential stays outside your repository.

## Pin the model id, and expect to type it

**Fetch available models** asks your endpoint what it serves, using the base URL, protocol and key in the form, and opens a picker. [`GET /v1/models`](/features/models) returns every string your key can call. We did not verify whether dsh's discovery reads that listing shape, and its documentation calls discovery a convenience, not a guarantee. If it returns nothing, type the ids. They work the same.

Make `unirouter/auto` the default. One trap the project names: a built-in provider is always answered from the installed catalog, even with a different base URL. Add this API as a custom provider, not as a built-in one with the URL changed.

## Set the maximum output

The per-model form has a maximum output field, so dsh is a harness where the advice on [coding harnesses](/integrations/coding-harnesses) is actionable. A realistic ceiling holds less against your spend rate cap and is charged the same. See [rate limits and spend controls](/manage/spend-controls).

## Images have to be declared

A model you type by hand is treated as text-only, because nothing can ask an endpoint which modalities it accepts. Attaching an image to it is refused before sending, naming the model. The form has no field for this, so add it to the file:

```yaml $DSH_HOME/settings.yaml
llm-pi-ai:
  providers:
    hopscotch:
      api: openai-completions
      baseURL: https://api.hopscotchlabs.ai/v1
      apiKeyEnv: HOPSCOTCH_API_KEY
      models:
        - id: unirouter/auto
          input: [text, image]
```

`defaultInput` on the provider does the same for every model under it. Both state a claim rather than check it, so declaring images on a model that this API routes to a text-only model is not caught here. Check `vision` in the model's `capabilities` block first. [Image inputs](/features/image-inputs) covers what this API accepts.

## If the gateway refuses everything

The adapter picks a request shape partly from the endpoint's address, and an unrecognised address is treated as OpenAI. Two consequences cause most refusals. A model that declares reasoning has its system prompt sent with the `developer` role, and the output cap is sent as `max_completion_tokens`. A server that wants `system` and `max_tokens` refuses both.

The switches are on the route, and a model's own value wins field by field:

```yaml $DSH_HOME/settings.yaml
llm-pi-ai:
  providers:
    hopscotch:
      compat:
        supportsDeveloperRole: false
        maxTokensField: max_tokens
```

We do not tell you to set these. We have not run dsh here, so we do not know this API needs either, and a switch you do not need just sends a different request. This section is for when only reasoning models fail, or when every request is refused while the key and URL are right. Those two symptoms usually have this cause.

## It shares its adapter with Pi

The `llm-pi-ai` plugin wraps the same library [Pi](/integrations/pi) uses. The compatibility vocabulary and per-model fields are recognisably the same, so a setting worked out on one is usually the same on the other, under a different key. That is a convenience, not a guarantee.

## What we did not verify

- That a dsh session against this API succeeds. Nothing was run.
- Whether model discovery reads this API's listing shape.
- Whether a model id from the form or the file is sent as the `model` field byte for byte. A mismatch shows as `400` with `model_id_not_pinned` or `404` with `model_not_found`, and neither costs anything.
- Which `compat` switches this API needs, if any.
- Whether any plugin in a default profile calls an embeddings endpoint. The optional overlays include memory servers, which usually do. We did not audit them.
- How stable any of this is. The project is a developer preview iterating quickly.
